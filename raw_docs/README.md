# Директория входящих материалов (Raw Knowledge Inbox)

Сюда можно скидывать любые сторонние материалы, посты, мануалы, даташиты и заметки:

```
raw_docs/
├── pdf/     # Даташиты микросхем (PMIC, Snapdragon, Camera OV64B), схемы, мануалы
├── posts/   # Сохраненные посты с 4PDA, XDA, Reddit, Habr, блогов (HTML, TXT, MD)
└── notes/   # Черновики, заметки, логи экспериментов, выжимки из чатов
```

## Как эти материалы превращаются в знания кластера:

1. **Автоматическая конвертация:**
   Запустите скрипт из корня проекта:
   ```bash
   python scripts/ingest_docs.py
   ```
   Скрипт прочитает PDF/TXT/HTML, очистит от лишнего мусора, структурирует по главам (`# Заголовок`, `## Секции`) и аккуратно сохранит готовые `.md` документы в директорию `cluster_docs/`.

2. **Индексация в оффлайн-RAG (1-3 мс):**
   При запуске `python scripts/build_local_kb_sqlite.py` (или через веб-студию `http://127.0.0.1:8090`) все статьи автоматически попадут в `datasets/omni_knowledge.db` (SQLite FTS5). База мгновенно реплицируется на смартфоны кластера.

3. **Компиляция в датасет для дообучения нейросети (LoRA):**
   В веб-студии на порту `:8090` во вкладке «1. SFT Датасеты» нажмите кнопку **«⚡ Сгенерировать датасет»**. Все секции новых документов превратятся в пары Вопрос-Ответ (формат ChatML) в файле `datasets/triad_omni_sft_dataset.jsonl` для последующего обучения в Colab.

4. **Прямой запрос агенту:**
   Вы также можете просто скинуть файл в чат с просьбой: *"Разбери этот даташит/пост и добавь в базу знаний кластера"*. Агент сам извлечет ключевые таблицы регистров, команды и грабли, оформив готовую статью в `ARTICLES/`.
