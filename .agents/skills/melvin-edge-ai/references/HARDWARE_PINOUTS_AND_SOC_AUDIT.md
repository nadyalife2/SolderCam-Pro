## 1. Точные распиновки разъемов и электрические параметры

### 1.1. Разъем Micro-USB Type-B (5 контактов)
Используется на хост-устройстве (Redmi Note 4 `nikel`, контроллер MediaTek Helio X20 / PMIC MT6351).

```
          ┌─────────────────────────┐
          │   [1]  [2]  [3]  [4]  [5]   │  (Вид со стороны контактов штекера,
          └───────\         /───────┘   широкой стороной вниз)
                   \_______/
```

| Контакт | Название | Цвет провода | Напряжение / Сигнал | Назначение |
| :---: | :---: | :---: | :---: | :--- |
| **1** | **VBUS** | Красный | **+5.0V DC** (до 500 мА в режиме OTG) | Питание шины USB. |
| **2** | **D-** | Белый | **0.0 – 3.3V** (LVTTL diff) | Отрицательная линия дифференциальных данных. |
| **3** | **D+** | Зеленый | **0.0 – 3.3V** (LVTTL diff) | Положительная линия дифференциальных данных. |
| **4** | **ID** | (нет провода) | **1.8V логика** (подтяжка внутри PMIC) | **Сенсор режима OTG / Host.** |
| **5** | **GND** | Черный | **0.0V** | Земля (общий провод питания и сигнала). |

#### Правила коммутации контакта 4 (ID):
* **Режим Device (Клиент):** Пин 4 не подключен (Float / сопротивление $>100$ кОм). Телефон принимает команды и заряжается.
* **Режим Host (OTG):** **Пин 4 замкнут на Пин 5 (GND)** напрямую (сопротивление $\le 10$ Ом). Контроллер телефона переключается в режим Хоста и включает выдачу +5V на Пин 1.
* ⚠️ **КРИТИЧЕСКИЙ ЗАПРЕТ:** Запрещено подавать напряжение с Пина 1 (VBUS +5V) на Пин 4 (ID). Линия ID внутри PMIC рассчитана на опорное напряжение 1.8V. Попадание 5V выжигает внутренний компаратор и логику детектора USB навсегда.
* ⚠️ **ЗАПРЕТ КЗ:** Пин 1 (VBUS) и Пин 5 (GND) не должны замыкаться. КЗ приводит к перегрузке внутреннего Step-Up DC-DC конвертера телефона.

### 1.2. Разъем USB Type-A (4 контакта)
Стандартный полноразмерный разъем USB 2.0 (на ПК, хабах и ТВ-приставках).

```
          ┌────────────────────────┐
          │  [1]   [2]   [3]   [4]  │  (Пластиковый язычок разъема сверху)
          └────────────────────────┘
```

| Контакт | Название | Цвет провода | Напряжение / Сигнал | Назначение |
| :---: | :---: | :---: | :---: | :--- |
| **1** | **VBUS** | Красный | **+5.0V DC** | Линия питания. |
| **2** | **D-** | Белый | **0.0 – 3.3V** | Данные USB High-Speed / Full-Speed. |
| **3** | **D+** | Зеленый | **0.0 – 3.3V** | Данные USB High-Speed / Full-Speed. |
| **4** | **GND** | Черный | **0.0V** | Земля / Общий провод. |

#### ⚠️ Смертельная ловушка: Кабель USB-A $\leftrightarrow$ USB-A для ТВ-боксов (Встречные 5 Вольт)
* Большинство китайских ТВ-боксов (X96, Vontar, Tanix, TOX3) имеют внешнее питание (адаптер 5V/2A или 12V DC).
* Их встроенные порты USB-A **постоянно находятся под напряжением +5V на Пине 1**.
* Телефон в режиме OTG **также выдает +5V на Пин 1**.
* Если соединить телефон и включенную приставку стандартным 4-жильным кабелем USB-A $\leftrightarrow$ USB-A:
  Два стабилизатора напряжения оказываются соединены параллельно без диодной развязки. Разница даже в 0.1–0.2 В порождает паразитный обратный ток силой в несколько ампер, что выжигает цепи питания USB в телефоне или приставке.
* **Решение:** Для подключения к ТВ-приставкам с собственным питанием использовать **кабель Data-Only (VBUS Cut)**:
  * Пин 1 (VBUS +5V) — **разомкнут / отрезан / заклеен каптоновым скотчем**.
  * Пин 2 (`D-`), Пин 3 (`D+`) и Пин 4 (`GND`) — **подключены обязательно** (Земля необходима для общего опорного уровня сигналов 3.3V).

### 1.3. Разъем USB Type-C (24 контакта, симметричный)

```
      A1   A2   A3   A4   A5   A6   A7   A8   A9   A10  A11  A12
     ┌────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┐
     │GND │TX1+│TX1-│VBUS│CC1 │D+  │D-  │SBU1│VBUS│RX2-│RX2+│GND │
     ├────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
     │GND │RX1+│RX1-│VBUS│SBU2│D-  │D+  │CC2 │VBUS│TX2-│TX2+│GND │
     └────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘
      B12  B11  B10  B9   B8   B7   B6   B5   B4   B3   B2   B1
```

* **Питание VBUS:** Контакты `A4, A9, B4, B9` соединены параллельно (+5.0V .. 20.0V).
* **Земля GND:** Контакты `A1, A12, B1, B12` соединены параллельно (0V).
* **Данные USB 2.0:** `A6/B6 (D+)` и `A7/B7 (D-)`.
* **Управление ролью (CC1 / CC2):**
  * В Type-C нет контакта ID. Роль хоста/устройства задается резисторами на линиях CC (`A5` и `B5`):
    * **Хост (DFP / Источник):** подтяжка линии CC к VBUS через резистор **56 кОм** (стандартный USB ток 500/900 мА).
    * **Устройство (UFP / Клиент):** подтяжка линии CC к GND через резистор **5.1 кОм ($R_d$)**.
  * Если в пассивном переходнике `USB-A (мама) -> Type-C (папа)` отсутствует резистор 5.1 кОм на землю, целевое устройство Type-C не включит прием данных по линиям D+/D-.

## 2. База данных производителей флеш-памяти (JEDEC CID `manfid`)

При чтении контроллера eMMC/UFS через ядро Linux (`cat /sys/block/mmcblk0/device/manfid` или `cat /sys/block/sda/device/vendor`):

| `manfid` (Hex / Dec) | Производитель | Примечание по надежности и скорости |
| :---: | :--- | :--- |
| **`0x15` / `21`** | **Samsung Electronics** | Золотой стандарт (высокий ресурс ячеек TLC/MLC, чипы KLMBG, KLMCG). |
| **`0x90` / `144`** | **SK Hynix** | Оригинальные качественные чипы eMMC 5.1 и UFS 2.1/3.1. |
| **`0x11` / `17`** | **Kioxia / Toshiba** | Высокая надежность, устанавливается в брендовые ТВ (Sony, TCL). |
| **`0x13` / `19`** | **Micron Technology** | Надежная память, часто встречается в американских и европейских приставках. |
| **`0x45` / `69`** | **SanDisk / Western Digital** | Распространенные чипы (iNAND), хорошая скорость последовательного чтения. |
| **`0x70` / `112`** | **Kingston** | Средний сегмент, частый компонент китайских приставок среднего уровня. |
| **`0x88` / `136`** | **Foresee (Longsys)** | Бюджетные китайские чипы, склонны к деградации при перегреве выше 75°C. |

## 4. Команды аудита аппаратной части через ADB

```bash
# 1. Процессор и платформа:
getprop ro.board.platform
getprop ro.hardware
cat /proc/cpuinfo | grep -E "Hardware|Processor|CPU part|Features"

# 2. Видеоядро (GPU) и версия OpenGL:
dumpsys SurfaceFlinger | grep -E "GLES:|OpenGL"
getprop ro.hardware.egl

# 3. Оперативная память (ОЗУ):
cat /proc/meminfo | grep -E "MemTotal|MemAvailable"

# 4. Встроенный накопитель (Тип eMMC vs UFS):
ls -d /sys/block/mmcblk0 2>/dev/null && echo "STORAGE: eMMC"
ls -d /sys/block/sda 2>/dev/null && echo "STORAGE: UFS"
cat /sys/block/mmcblk0/device/name 2>/dev/null
cat /sys/block/mmcblk0/device/manfid 2>/dev/null
df -h /data

# 5. Проверка статуса Root и безопасности:
which su 2>/dev/null
ls -d /data/adb/magisk 2>/dev/null
getprop ro.build.tags
getenforce
```
