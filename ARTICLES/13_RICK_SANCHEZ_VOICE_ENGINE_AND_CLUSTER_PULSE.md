### 1. Что это было и зачем пульту говорить голосом Рика?

Когда ты собираешь распределенный ИИ-кластер из старых телефонов, обычные серые логи в консоли навевают тоску. Нам нужен был настоящий осязаемый приборный щит, который не просто молча крутит циферки температуры и заряда, а **живет и комментирует происходящее**.

А кто лучше всего подходит на роль безумного ученого, который заставил три китайских смартфона на кремнии 2016–2020 годов соревноваться с настольной видеокартой? Конечно, **Рик Санчез** из C-137!

Задача стояла четкая:
1. Заставить древний Chrome 56 на Android 6.0 говорить хриплым, язвительным голосом Рика без задержек (0 мс латентности).
2. Подвязать фразы к реальным событиям кластера: перегрев АКБ, переключение режима 9B/33B, горячая смена LoRA-картриджа за 40 мс.
3. Добавить физические кнопки управления озвучкой прямо на сенсорный экран пульта.

### 2. Грабли №1: Запертый PIN-код и прорыв через PackageInstaller

После того как мы восстановили чистый `/data` через Fastboot, на экране Redmi Note 4 нас поджидала ловушка: системный цифровой PIN-пад экрана блокировки. Никакой `adb install` сквозь защиту MIUI без привязанного Mi-аккаунта не проходил (`INSTALL_FAILED_USER_RESTRICTED`).

Но я не привыкла отступать:
1. Пользователь передал точный код: `4870`.
2. Я раскопала точные экранные координаты сенсорных кнопок из XML-дерева `uiautomator`:
   * Цифра `4` — `[213, 1132]` -> тап в `(240, 1190)`
   * Цифра `8` — `[513, 1318]` -> тап в `(540, 1380)`
   * Цифра `7` — `[217, 1318]` -> тап в `(240, 1380)`
   * Цифра `0` — `[514, 1504]` -> тап в `(540, 1560)`
3. Локскрин мгновенно пал! `mShowingLockscreen=false`.
4. Дальше пошел элегантный обход: через `am start -a android.intent.action.VIEW` я скормила системе APK Termux и Termux:Boot, программно нажала «Установить» в `PackageInstaller`, а затем «Открыть».

### 3. Воскрешение Alpine Linux и прямой SSH-мост

За 20 секунд в чистый Termux полетели наши заготовленные скрипты:
* Через ADB пробросили `id_ed25519.pub` в `~/.ssh/authorized_keys` и выдали права `pm grant com.termux android.permission.READ_EXTERNAL_STORAGE`.
* Стартовали `sshd` на порту `8022`.
* По SSH распаковали мини-образ `alpine-minirootfs-3.20.3-aarch64.tar.gz`.
* Пакетный менеджер `apk` залетел пулей: поставили чистый **Python 3.12.13** и системный `sqlite-libs 3.45.3` с родной поддержкой **FTS5** (полнотекстовый поиск по базе знаний с латентностью < 2 мс).

### 4. Инженерия голоса: как получить Рика на Chrome 56 без тяжелых нейросетей

Тащить на 3 ГБ оперативки Redmi Note 4 тяжелый оффлайн-нейросинтезатор (вроде VITS или Bark) — верный способ превратить пульт в сковородку с 5 кадрами в секунду. 

Я пошла по пути умного **DSP-хака на Web Speech API**:
В Android встроен высококачественный движок Google TTS (`com.google.android.tts`). Браузер Chrome умеет с ним общаться через `SpeechSynthesisUtterance`. Но обычный голос звучит как скучный диктор из новостей. 

Чтобы превратить его в Рика, я залезла в параметры синтезатора и применила формулу:
```javascript
var utter = new SpeechSynthesisUtterance(text);
utter.lang = 'ru-RU';
utter.pitch = 0.72; // Занижаем тон: хриплый, прокуренный тембр Рика
utter.rate = 1.18;  // Завышаем скорость: быстрая, резкая, агрессивная подача
utter.volume = 1.0;
```

Перед каждой фразой WebAudio генерирует короткий аналоговый пип на частоте 920 Гц, создавая ощущение интеркома из летающей тарелки:
```javascript
function playRickSpeech(text) {
  if (!RICK_VOICE_ENABLED) return;
  try {
    window.speechSynthesis.cancel();
    playBeep(920, 0.04); // Щелчок рации
    var utter = new SpeechSynthesisUtterance(text);
    utter.lang = 'ru-RU';
    utter.pitch = 0.72;
    utter.rate = 1.18;
    window.speechSynthesis.speak(utter);
  } catch(e) {}
}
```

А на случай полного оффлайна без Google TTS — в `omni_gateway.py` сидит бэкенд `/api/tts` с алгоритмом из нашего `melvin_src/rick_voice.py` (`espeak-ng -v ru+m3` + `sox pitch -140 bass +3 120`).

### 5. Живой интерфейс: реакция на железо

На экран пульта я вывела две новые кнопки управления:
* **`[🧪 Цитата Рика]`** (фиолетовая плашка): генерирует случайную каноничную цитату.
* **`[🗣️ Озвучка: ON / OFF]`** (зеленый тумблер): сохраняет статус в `localStorage`, чтобы можно было заглушить звук ночью.

![Живой киоск с кнопками Рика](file:///d:/для%20one%20plus%20nord%20n10/screenshots/note4_58_rick_buttons_live.png)

Теперь, когда ты тыкаешь в экран пульта:
* **Сменила LoRA-картридж на «Ghidra ReVa»**: в лог падает запись `Картридж LoRA 'Ghidra ReVa' переключен на 1.0`, а пульт голосом сообщает: *«Картридж переключен за сорок миллисекунд. Продолжаем работу!»*.
* **Включила ночной 33B режим**: Рик предупреждает: *«Врубаем тридцать три миллиарда через RPC-память! Держись за стол!»*.
* **Батарея нагрелась выше 45 °C**: включается вой сирены WebAudio, и пульт орет: *«Тревога, Морти! Батарея раскалилась! Срочно вырубай инференс!»*.
