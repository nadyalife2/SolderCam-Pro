# ⚡ Triad-Omni v5.2: Пакет для обучения Fast-Tool Harness Adapter в Google Colab

Архив содержит все необходимые файлы для обучения ультра-быстрого Zero-CoT картриджа инструментов для базовой модели **Qwen3.5-9B** (или Qwen2.5-7B) на GPU Tesla T4.

## 📦 Состав архива:
1. 	riad_omni_trainer.ipynb — обновленный блокнот обучения Google Colab с поддержкой Qwen3.5-9B (4-bit), LoRA r=32/alpha=64 и автоматической выгрузкой архива на Google Drive.
2. datasets/triad_omni_harness_sft.jsonl — готовый датасет (180 проверенных многошаговых диалогов) без раздувания токенов рассуждений (<think>).
3. uild_harness_adapter_sft.py — генератор датасета, если захочешь добавить свои сценарии или системные инструменты.
4. deploy_to_mi10t.py — скрипт быстрой отправки готового архива картриджа на Xiaomi Mi 10T 5G через ADB.
5. card.json — паспорт картриджа v5.2-harness.
6. cartridge_manager.py — менеджер версий и проверка целостности паспорта.

## 🚀 Пошаговая инструкция по запуску:
1. Открой [Google Colab](https://colab.research.google.com/).
2. Выбери: **Файл** -> **Загрузить блокнот** -> выбери файл 	riad_omni_trainer.ipynb из этого архива.
3. В верхнем меню Colab выбери: **Среда выполнения** -> **Сменить среду выполнения** -> выбери **T4 GPU** (бесплатный).
4. Запусти ячейку №1 (настройки и установка Unsloth).
5. Запусти ячейку №2 (загрузка unsloth/Qwen3.5-9B-Base в 4-bit и монтаж LoRA-слоев).
6. В ячейке №3 нажми «Выбрать файлы» и укажи 	riad_omni_harness_sft.jsonl из папки datasets/ (или оставь дефолтную ссылку).
7. Запусти обучение! На Tesla T4 80-100 шагов займут всего ~7-10 минут.
8. Ячейки №4 и №5 автоматически сконвертируют веса в dapter.gguf, упакуют архив 	riad-omni-fast-tool_v5.2.omni.zip и выгрузят его прямо в твою папку Google Drive (1UNP2g3jOfGjxCUDhBDQtMuEFvoESBp1K)!
